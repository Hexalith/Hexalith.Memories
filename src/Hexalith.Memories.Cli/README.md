# Hexalith.Memories.Cli

Global .NET tool for Hexalith.Memories developer and operator workflows.

Install the tool from NuGet:

```powershell
dotnet tool install --global Hexalith.Memories.Cli
```

Then run:

```powershell
memories --help
```

The CLI uses the REST client surface and supports Memories search, ingestion, case, handler, and
diagnostic workflows exposed by the server.
