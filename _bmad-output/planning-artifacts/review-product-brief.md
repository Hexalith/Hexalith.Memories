## Verdict

The 2026-09-05 Update did split the brief’s v1 contract: Phase 1 is now a CLI thesis (hybrid + isolation + file/URL ingest) and Phase 1.5 is the launch path for MCP and EventStore product integration, with two clocks, two go/no-go tables, and explicit `[NON-GOAL for MVP]` tags. That split is real. What still leaks is identity and FR placement, not the gate tables: Causal Intelligence FR46–FR52 sit in the MVP register while the same document forbids claiming causal three-axis on a folder tree; the Executive Summary and Innovation #1 still sell an LLM-agent / discussion / EventStore-causal hero as what the product *is*; the LLM Agent token-budget success row has no phase tag. Qualitative residue the Update claimed to park is in the addendum. Several brief ecosystem metrics vanished without a Non-Goal or phase tag. Expansions the addendum said must leave the product contract (Aspire/OpenBao as NFR, package tables, interpretive-compliance program) are still sitting in `prd.md`.
