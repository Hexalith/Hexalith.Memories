# Hexalith.Memories.Contracts

Shared contracts for Hexalith.Memories clients, servers, and tooling.

Use this package when a consumer needs request and response models for memory ingestion, search,
case management, traversal, and related result payloads without depending on a concrete transport
or storage implementation.

```powershell
dotnet add package Hexalith.Memories.Contracts
```

See the Hexalith.Memories repository for service setup, API workflows, and contributor guidance.
