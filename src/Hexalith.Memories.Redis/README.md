# Hexalith.Memories.Redis

Redis, RediSearch, and FalkorDB adapters for Hexalith.Memories.

Use this package inside Memories services that need the Redis-backed syntactic, semantic, graph,
tenant-provisioning, and operational persistence implementations.

```powershell
dotnet add package Hexalith.Memories.Redis
```

This package is infrastructure-facing. Application consumers normally use the REST client, CLI, or
server deployment surface instead.
