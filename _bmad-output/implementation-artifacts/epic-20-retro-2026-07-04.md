## What Went Well

1. **Audit-anchor preflight became a working safety practice.**
   Each story re-verified stale audit line anchors against current code before implementation. That prevented the team from fixing old line numbers instead of current risks.

2. **Security failures moved earlier in the request path.**
   20.1 rejects anonymous API traffic before handlers run. 20.2 denies cross-tenant access before business dependencies execute. 20.3 authorizes stored workflow/batch ownership before returning status or fan-out. 20.5 rejects over-limit requests before endpoint work.

3. **Review fixes caught real edge cases.**
   Senior reviews found missing actor anonymous-route inventory, malformed tenant bypass behavior, spoofable lookup audit identity, unreadable workflow-state handling, split rate-limit quota stores, display-name audit error-code loss, and incomplete story file lists.

4. **Tests targeted negative security behavior.**
   The epic added route inventory guards, cross-tenant denial tests, principal-derived audit tests, safe DTO serialization tests, MCP production config tests, request-rate-limit rejection tests, and adversarial RediSearch escaping tests.

5. **The Epic 19 handoff pattern held.**
   Stories 20.1 and 20.2 cross-linked and resolved the existing auth and tenant-authorization deferred entries instead of duplicating backlog homes.

## Challenges

1. **Architecture and operator docs lagged behind implementation.**
   `architecture.md` still framed `TenantAuthorizationMiddleware` as deferred Phase 1.5 work. Deployment and MCP docs still contained stale Server-auth and `memories-server` upstream language.

2. **Status and telemetry docs became stale during implementation.**
   Route documentation did not describe the new safe `IngestionWorkflowStatus` projection, and telemetry docs still described only the older five audit operation families with spoofable/header-based user resolution.

3. **A41 was intentionally split.**
   Inbound request limiting and mutation audit coverage landed, but access-telemetry retention/TTL did not. The story correctly deferred it, but future planning must not treat A41 as completely closed until retention is resolved.

4. **Test-runner environment remains a recurring workflow concern.**
   The known VSTest TCP listener sandbox failure recurred. The xUnit v3 executable fallback is now routine, but story evidence must keep distinguishing environment blockers from product test failures.

5. **Epic 20 increased cross-cutting surface area in `Program.cs`.**
   The changes were intentionally scoped, but auth, tenant filtering, rate limiting, audit wrappers, and status handling all reinforce the need for Epic 25 route/composition factorization after security posture stabilizes.
