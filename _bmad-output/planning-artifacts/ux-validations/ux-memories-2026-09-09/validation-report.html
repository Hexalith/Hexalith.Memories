_bmad-output/planning-artifacts/ux-design-specification.md + ux-design-directions.html

Broken as a downstream UX contract. The legacy package preserves a strong trust-centered direction and unusually thoughtful accessibility intent, but it is not a DESIGN.md / EXPERIENCE.md spine pair, covers only part of the current PRD journey set, and has drifted from current phase, command, authorization, scoring, and lifecycle contracts.

The most urgent correction is security semantics: cross-tenant or tenant-claim-mismatched requests must fail closed, never become confirmable scope expansion. Web implementation should remain activation-gated until exact FrontComposer/Fluent ownership and accessibility evidence contracts are written; the active CLI needs an accessible terminal-output contract now.
